# Brian Wheeler Portfolio

Recruiter-focused portfolio built with Next.js and designed for deployment on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

1. Replace `REPLACE_ME@example.com` in `app/page.tsx` with your real contact email, or remove the email button.
2. Add your resume to `public/` later and link it from the homepage when ready.
3. Replace the placeholder links for Green Parts Inventory and the automation toolkit when their case-study pages are ready.

## Deploy to Vercel

Import the GitHub repository into Vercel and use the default Next.js settings. No environment variables or database are required.
